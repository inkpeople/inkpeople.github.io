# FIT/FORGE — подключение к Telegram Mini App

## Что уже подготовлено в приложении

- Подключена официальная библиотека Telegram Web Apps.
- Приложение вызывает `ready()` и `expand()`, когда открыто внутри Telegram.
- Использует тёмные цвета заголовка и фона Telegram.
- Показывает инициалы пользователя Telegram в аватаре, если Telegram передал профиль.
- Поддерживает кнопку «Назад» Telegram для навигации между разделами.
- Использует лёгкую тактильную обратную связь, если она поддерживается устройством.
- Включает предупреждение при закрытии Telegram Mini App во время начатой тренировки.
- Данные тренировок пока сохраняются локально в браузере этого устройства.

## URL приложения

`https://inkpeople.github.io/workout-trainer/`

## Как включить приложение в меню бота

1. Открой официальный аккаунт **@BotFather** в Telegram.
2. Отправь команду `/setmenubutton`.
3. Выбери бота **@MyFitnessTrainer_Ramzes_bot**.
4. Укажи название кнопки, например `FIT/FORGE`.
5. Укажи URL приложения: `https://inkpeople.github.io/workout-trainer/`.
6. Открой чат со своим ботом и нажми появившуюся кнопку меню.
7. Проверь запуск приложения, переходы по разделам, отметку подхода и сохранение данных после перезагрузки.

Если BotFather попросит настроить домен, укажи `inkpeople.github.io` и следуй подсказкам BotFather.

## Важно

- Не отправляй токен Telegram-бота в чат и не помещай его в HTML/JavaScript.
- Наличие Telegram WebApp SDK не означает, что бот уже настроен: кнопку меню нужно включить через BotFather.
- Сейчас нет серверной проверки `initData`, серверной базы данных и синхронизации между устройствами.
- AI-тренер на базе языковой модели пока не подключён. Не показывай пользователю, будто такие функции уже работают.
- Чтобы получить безопасную авторизацию и общую историю на нескольких устройствах, следующим этапом потребуется backend, который проверяет подпись Telegram `initData` и хранит данные пользователя с разграничением доступа.
- Данные localStorage могут быть потеряны при очистке данных браузера. Используй экспорт резервной копии в разделе «Прогресс».
